# backstage-api-specs

This repository contains OpenAPI specifications for services registered in the Backstage developer portal.

## APIs

| API | Description |
|-----|-------------|
| [Products API](./products-api.yaml) | CRUD API for managing products |
| [Football Results API](./football-results-api.yaml) | Fixtures, scores, teams and standings |

## Adding a new API

Use the **OpenAPI Service** template in the [Backstage catalog](http://localhost:3000/create) to scaffold a new API spec.
