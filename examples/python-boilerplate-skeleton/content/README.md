## Getting Started

### Prerequisites
- Python 3.11+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip

### Install dependencies

```sh
uv sync
# or
pip install -r requirements.txt
```

### Run the app

```sh
python -m src.main
```

### Run tests

```sh
pytest
```
